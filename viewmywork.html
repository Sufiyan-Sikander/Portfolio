ChurnInsight-AI

ChurnInsight-AI is an AI-powered machine learning web application that predicts whether a bank customer is likely to leave the service. It is built using Streamlit for the frontend interface and TensorFlow/Keras for deep learning inference. The system takes user inputs such as geography, gender, age, balance, credit score, salary, and account activity, then preprocesses them using trained encoders and a scaler before feeding them into a neural network model.

  • TensorFlow/Keras deep learning model for churn classification

  • Label encoding for binary categorical feature (Gender)
  • StandardScaler for feature normalization
  • Real-time probability output with threshold-based classification logic
